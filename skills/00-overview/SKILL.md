# 审计数据处理的工具分流

## 先看输入是什么

| 手上是什么 | 要拿到什么 | 用哪个 |
|---|---|---|
| 一堆 Word（.docx / .doc） | 命中关键词的文件与段落清单 | **01**（.docx）、**01B**（含 .doc 老格式） |
| 一堆混合文档，目录层级很乱 | 全盘范围内命中位置 + 段落摘要 | **S** 关键词搜索工具 |
| 两份文本 / 两个版本的制度文件 | 增删改的逐处差异 | **07** 文本文档比对工具 |
| 一张或多张 Excel | 按字段拆分、合并、或按 Sheet 合并 | **12** 拆分、**13** 多表合一、**14** 多页合表 |
| 两张表要按某个键对应起来 | 关联后的宽表 | **02** 关联查询（简单键值）、**03** 关系建模（多表、要看图） |
| 图片、扫描件、图片式 PDF | 可编辑的 Word 文字 | **04** 图片文字识别 |
| 发票图片 | 结构化发票信息表 | **08** 发票识别 |
| 批量 PDF 电子发票 | 一张汇总表 | **09** 发票信息批量提取 |
| 身份证照片 / 一批身份证号 | 结构化信息、归属地 | **10** 身份证手机号识别 |
| 文本式 PDF（能选中文字） | 正文 Word / 表格 CSV / Excel | **05** 正文与表格、**06A** 数据表（银行流水类） |
| PDF 要整篇换格式 | 转换后的文件 | **06B** PDF 文件转换 |
| 录音、谈话笔录音频 | 文字稿 | **11** 语音识别 |
| 英文财报 / 年报 / 审计报告 | 中英对照 Word | **15** 财务报表中英翻译器 |

## 三条判断原则

**一、能拿到文本层就别上 OCR。** PDF 里能选中文字，说明有文本层，走 05/06A 又快又准；
OCR 只在图片和扫描件上用，且识别结果必须人工复核关键字段（金额、日期、证件号、税号）。

**二、拆分 / 合并 / 关联是三件事，别混。**
12 是「一个文件按字段切成多个」，13 是「多个文件纵向拼成一个」，14 是「一个文件里多个 Sheet 拼成一张」，
02/03 是「两张表按主键横向拼」。搞错方向会得到一张行数不对的表。

**三、先查行数，再看内容。** 任何拆分、合并、关联之后，第一件事是核对行数守恒或主键唯一性；
数字对不上时，问题通常出在表头行、合并单元格、前导零被转成数字这三处。

## 组合用法（真实的活通常是连着做的）

- **凭证抽查**：S 全盘搜出含关键词的文件 → 01 在 Word 里定位段落 → 07 比对制度新旧版本。
- **银行流水核对**：06A 把 PDF 流水转 Excel → 02 与被审计单位账套按日期+金额关联 → 12 按账户拆开分人核对。
- **发票专项**：09 批量提取电子发票 → 08 补识别纸质发票 → 02 与合同台账关联查缺票。
- **境外子公司**：15 把英文报表译成中英对照 → 06A 提取附注表格 → 14 合并多期数据做趋势。
- **谈话取证**：11 转写录音 → 07 与笔录模板比对，标出未覆盖的问题点。

## 工具不在本机时

包内只提供清单与启动台，官方工具需要按 `tools.json` 的相对路径自行放入 `组件/`。
先跑 `python scripts/verify_toolbox.py --root <工具箱目录>`，它会告诉你缺哪个、哪个版本被换过。
