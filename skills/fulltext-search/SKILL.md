# 关键词搜索工具（S）

跨格式撒网：一个文件夹里混着 Word、PDF、扫描件、Excel，一次搜完，命中的段落连上下文一起摘出来，原件另存一份。

## 什么时候用
- 刚接收一批资料，不知道线索在哪，先拿几个关键词全面扫一遍，摸清资料构成。
- 要找的证据可能藏在扫描版 PDF 或 Excel 里，Word 专用检索工具覆盖不到。
- 要给组长或主审一份「命中清单＋段落摘要」，不必让他逐份翻原件。
- 需要把命中文件单独挑出来，用于归档、移交或送检。
- 不适合：只搜 docx 且要精确段落清单，用 01 更快更干净（它不做评分过滤）；只搜老 .doc 用 01B；只要提取不要检索用 PDF/OCR 提取类工具；表内按字段做关联统计用 02/03。

## 准备
- 工具位置：`组件/搜索工具/关键词搜索工具.exe`（关键词搜索工具 v2.0 版，随工具包分发）
- 支持 doc、docx、pdf、xls、xlsx。扫描版 PDF 靠内置中文 OCR 识别，纯图片 PDF 也能搜，但速度慢，准确率取决于扫描清晰度。
- 源文件夹要可读，路径别太深；不要把范围指到整个系统盘，会扫进大量系统与缓存文件。
- 导出文件夹必须与源文件夹分开，最好另建一个空目录，否则命中的原件会被复制回源目录，越跑越多。
- 导出盘留足空间：命中文件是整份复制，不是只存片段；全程离线。
- 先把关键词列成清单（同义词、简称、项目名、关键金额），一次跑完比反复跑省时间。
- Windows 7 机器用包内 Win7 版程序，新版 exe 在 Win7 上会因缺运行库启动失败。

## 操作
1. 先数一遍源文件夹的文件总数和大致构成（多少 Word、多少 PDF、多少 Excel），这是后面的验收基准。
2. 选源文件夹（要搜的那一层），再选导出文件夹（另建的空目录）。
3. 决定是否启用智能冗余过滤：做「有没有提到」的全量核查时关闭，做「挑重点线索」时开启。
4. 选模式：严格模式过滤彻底但可能漏检；宽松模式保留更多，宁多不漏时选它。
5. 开始搜索并输入关键词；先用一个子目录试跑，看耗时和命中质量，再对全量开跑。
6. 扫描件多时按小时计，跑之前跟使用人打好招呼，中途不要移动或改写源文件夹。
7. 跑完先看搜索报告，再看摘要表，最后按需从命中文件目录取原件。

## 输出与验收
- 输出物：`匹配文档摘要.xlsx`（文件名、段落摘要，关键词以【】标出，带相关度评分和该文件匹配段落数，首行冻结）、`搜索报告.txt`（搜索参数、统计、命中文件列表）、`命中文件/`（命中原件副本）。
- 验收要点：报告里的扫描文件数与你事先数的源文件数对得上，差太多说明范围选错、权限不足或有子目录没读进去。
- 「该文件匹配段落数」顶到单文档上限（20 条）的文件已被截断，那份文件要单独再搜一次。
- 相关度评分低的行要抽看原文。评分只是排序参考，不能当「无关」的依据直接删。
- 结果条数为 0 时依次排查：关键词写法（全角、空格、繁简）、是否只搜了顶层目录、过滤是否过严（切宽松或关闭）、PDF 是否纯图片且 OCR 没识别出来、文件是否加密损坏、扩展名是否在支持范围内。
- 命中文件目录的份数要与摘要表里不同文件数一致，对不上说明有同名文件被覆盖。

## 坑
- 智能过滤会漏检。机构名后缀、参会名单、人员头衔、极短标题会被判为冗余并扣分丢弃，严格模式阈值高。做「全量核查有没有提到」时务必切宽松或关闭过滤，并把这一设置写进底稿。
- 单文档最多保留 20 条匹配，长文件、汇编类文件的命中会被截断，看着像只提了几次。
- OCR 对倾斜、低分辨率、表格线密集的扫描件错字多，命中只能当线索，不能作唯一证据；金额、编号类关键结论必须回原件核。
- PDF 表格被 OCR 拉平成文字流，数字容易串行错位，用它核对金额尤其危险。
- 命中文件是整份复制，含敏感信息，导出目录权限、交接和事后清理都要交代清楚。
- 导出目录若建在源目录之下，下一轮搜索会把上一轮的结果也算进去，命中数虚增。
- 过滤词库按通用公文写法设计，行业术语多的单位可能出现系统性误判。遇到这种漏检换宽松模式重跑，而不是逐条补。

## 与包内其他工具怎么配合
- word-keyword-search（01）/ word-doc-legacy-search（01B）：S 撒网定位后，docx 用 01、老 doc 用 01B 做精确段落复核，两套结果互相印证。
- text-diff（07）：定位到同一文件的两个版本后，用 07 比出差异。
- ocr-image（04）/ pdf-extract（05）/ pdf-convert（06B）：需要把 PDF 或图片转成可编辑文档时用它们，转完再回 S 或 01 检索。
- 数据分析关联查询工具（02）/ 表格数据关联工具（03）：命中 Excel 后要做字段关联、跨表核对，交给这两个。
