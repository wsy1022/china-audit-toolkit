# PDF数据提取工具（06A）

把银行、税务、被审计单位系统导出的 PDF 报表按页按表拆成多个工作表，是把外部数据拉进审计底稿最常用的一个动作。

## 什么时候用
- 银行提供的账户协查结果、开户信息、交易流水明细是 PDF，需要逐笔核对金额、日期、对方户名 → 表格模式出 Excel。
- 税务、社保、公积金、招投标平台导出的 PDF 报表要并进底稿台账。
- 一份 PDF 里有多个互不相干的表（封面说明、汇总表、明细表），想分开放、分别核 → 每页每表一个工作表，天然隔开。
- 只需要把 PDF 正文变成可编辑 Word（不加页码标题以外的东西）→ 文本模式也能用，但整篇转换更规整时应选 06B。
- 不适合：正文为主、表格只是零星穿插的制度、合同、会议纪要 → 用 05 PDF文件内容提取工具或 06B PDF文件转换工具，别为了几张表把全文拆成一堆工作表。
- 不适合：扫描件、图片式 PDF，没有文本层，出表为空；先走 04 图片文字识别工具。
- 不适合：需要保留原版式交付（盖章件、对外文书）→ 06B 更像原件。

## 准备
- 工具位置：`组件/审计署工具/06PDF内容提取工具/02安装包/Windows/PDF数据提取工具.exe`（官方发布，不在本仓库内）
- 输入要求：文本层 PDF；表格要有可见的行列线或至少规整的列对齐，纯空格排版的表容易被并成一列。
- 加密与权限：带打开密码的先解密；只有权限限制的（禁止复制），先手工复制一段验证能否取字。
- 篇幅：账户协查件常见几十到几百页，一次一份跑；超大批量按账号或按月份拆成多份，单份失败不牵连全部。
- 跨页表格：工具不跨页拼表，同一张明细表连着几页就会生成几个工作表，需要人工接。
- 环境：Windows 单文件 exe，双击即用，不装 Office 也能跑（生成的是标准 docx/xlsx）；部分杀毒软件对单文件 exe 误报，加入信任即可。
- 联网：本地处理，不联网。

## 操作
1. 双击 `PDF数据提取工具.exe` 启动，界面是单窗口，先出文件选择框。
2. 选择待处理的 PDF。
3. 先指定保存位置与文件名：要 Word 就存 `.docx`，要 Excel 就存 `.xlsx`。这一步决定产出类型，先想清楚再点。
4. 选择操作方式：`文本` 或 `表格`。做账户协查、流水核对的选 `表格`；只想要正文的选 `文本`。
5. 点转换，等提示完成。页数多的文件界面会短暂无响应，不要重复点击，也不要强行关闭。
6. 打开输出的 Excel/Word，先看页数与工作表数量，再逐表核对首行与金额列。

## 输出与验收
- 输出物：
  - 表格模式 → 一个 `.xlsx`，每页每个表一个工作表，命名为 `Page<页号> Table<序号>`，与原件的页序、表序一一对应。
  - 文本模式 → 一个 `.docx`，每页一段，页前插一行 `PDF Page <页号>` 作定位标记。
- 验收要点：
  - 页数是否齐——Excel 里看最大的 Page 号是否等于原件总页数；缺页多半是空白页被跳过，属正常，但要记下来。
  - 表头要自己补——输出不带表头行，原件第一行数据就落在第一行；核对前先插一行写字段名，否则后续关联全错位。
  - 表格列是否错位——抽查三到五页，比对原件列数与 Excel 列数；多出空列通常是合并单元格留下的。
  - 金额行是否漏——用原件该页的行数比对工作表行数，差额要回原件确认是否被并进上一行。
  - 跨页表怎么接——同一张表续到下一页时，下一页常重复表头，先删重复行再纵向追加；建议按"账号＋日期＋金额"去重核对笔数。
  - 金额是否变成文本——选中金额列看状态栏求和是否为 0，为 0 说明是文本格式，需先转为数值再统计。

## 坑
- 无表头是设计如此：输出工作表不带表头、不带索引，看起来"少了一行"，其实原件第一行就在那儿，别以为丢数据。
- 每页每表一个工作表：几十页的表单会生成几十个工作表，Excel 标签页极多，交付前考虑用 13 Excel多表合一 或 14 Excel多页合表 收拢。
- 重复表头：原件每页都印一遍表头时，每个工作表第一行都是表头，纵向合并必须先去重，否则笔数虚增。
- 合并单元格：跨行合并的户名、跨列合并的合计栏，提取后只在首格有值、其余为空，不能直接按列求和或填充。
- 跨页断行：一张表被页边界切开，末尾几笔落在下一个工作表，人工接表时最容易漏最后一行。
- 扫描件与加密件：产出空白行或空工作表，工具不一定报错，静默失败要靠页数核对发现。
- 文本模式的页标记：`PDF Page n` 是工具加的，不是原文，引用原文时删掉，交付稿里留着会被当成编辑痕迹。
- 页眉页脚混入：文本模式下每页的页眉、页码、水印会进正文，需成批清理。
- 输出被占用：目标 xlsx/docx 正在 Excel、WPS 里打开时保存失败，先关文件。

## 与包内其他工具怎么配合
- 04 图片文字识别工具：扫描版协查件先 OCR，再回到本工具做表格拆分。
- 03 表格数据关联工具：把拆出来的账户明细与账面往来、客户名单做关联比对。
- 02 数据分析关联查询工具：多份协查 Excel 汇总后做条件筛选、分组统计。
- 13 Excel多表合一 / 14 Excel多页合表：工作表太多或同一张表跨多页时，先合并再分析。
- 05 PDF文件内容提取工具：既要正文又要表格、且想一次拿到 CSV 时用它，但表格会拼成一张表。
- 07 文本文档比对工具：银行回单与合同条款各转文本后比对表述差异。
