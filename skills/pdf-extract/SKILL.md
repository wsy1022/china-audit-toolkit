# PDF文件内容提取工具（05）

把被审计单位交来的 PDF 资料变成可编辑的 Word 和可计算的 CSV，是审计取证里"先把纸面变成数据"的第一步。

## 什么时候用
- 制度、合同、会议纪要、批复、招投标文件是 PDF，需要通读、摘录、做批注或引用原文 → 转 Word。
- PDF 里夹着收费明细、人员名册、资金分配表这类规整表格，需要拉进 Excel 与账面数、银行流水核对 → 转 CSV。
- 一批 PDF 既要正文又要表格，想一次跑完，并留下"哪些文件处理过"的清单备查。
- 不适合：银行账户协查、流水明细、对账单这类"整份都是表格"的 PDF，用 06A PDF数据提取工具，直接出多工作表 Excel 更省事，也不用再拆 CSV 的列。
- 不适合：只是想把 PDF 换个格式存档、给不装 PDF 阅读器的人看，用 06B PDF文件转换工具，它专心做整篇转换。
- 不适合：扫描件、手机拍照转的 PDF、传真件——没有文本层，本工具只能得到空白或乱码，先走 04 图片文字识别工具。

## 准备
- 工具位置：`组件/审计署工具/05PDF文件内容提取工具/02安装包/Windows/PDF文件内容提取工具/PDF文件内容提取工具.exe`（官方发布，不在本仓库内）
- 输入要求：必须是文本式 PDF——用阅读器能选中、能复制文字。选不中字的，一律按扫描件处理。
- 加密与权限：有打开密码的 PDF 要先解密；只设了"禁止复制/禁止提取"权限的，工具往往不报错但输出空文件，转换前先手工复制一段文字试一下。
- 篇幅：几十页到一两百页可以整份跑；上千页建议按章节或按年度拆开，单次转换失败时不必整份重来。
- 跨页表格：工具按页提取，跨页的表天然会被切成两段，准备人工接表。
- 环境：绿色免安装，解压即用；同目录的 dll、pak、locales 等文件不能删、不能单独把 exe 拷走，否则起不来。
- 联网：本地处理，不联网，也不上传文件到外部服务——这点在涉密或敏感资料场景可以直接引用。
- 端口：程序在本地起一个服务，端口写在同目录的 properties.txt 里；若提示端口占用，改这个文件里的端口号再启动。

## 操作
1. 双击 exe 启动。第一次启动会写配置文件，稍等几秒界面才出来。
2. 点"添加文件"选择 PDF，可一次选多份；界面上会列出待处理清单。
3. 选择要做的事：正文转 Word、表格转 CSV，或两者都做。只想要数据的，别顺手把 Word 也生成，几百页的 Word 校对起来很费时。
4. 指定输出目录。建议按"被审计单位／资料类别／年度"建目录，输出文件名与原件同名，便于回溯。
5. 开始转换，等进度走完。中途不要打开输出目录里的临时文件，也不要关窗口。
6. 在工具的留痕列表里核对本次处理的文件与时间，把这份记录随底稿一起留存。

## 输出与验收
- 输出物：与原件同名的 `.docx`（正文，近似保留原版面）；与原件同名的 `.csv`（表格，把全文所有页的所有表纵向拼在一张表里）。
- 验收要点：
  - 页数是否齐——Word 里搜一下最后一页的页码或末段文字，确认没有被截断的尾部。
  - 表格列是否错位——CSV 用 Excel 打开，看首行表头有没有被拆成两列、金额列有没有串到摘要列。
  - 金额行是否漏——用原件表格的行数比对 CSV 的数据行数，差一行都要回原件看是哪一行被合并单元格吞了。
  - 跨页表怎么接——同一个表跨两页时，第二页往往重复表头或直接断行，CSV 里会出现一条只有半截字段的记录，按业务主键（户名、凭证号）手工拼回。
  - 中文是否乱码——Word 里抽查标题、单位名称，出现方块字说明字体缺失，换台装有中文字体的机器重跑。

## 坑
- 扫描件误判：PDF 能打开、能看，不等于有文本层。转换出来一片空白，多数不是工具坏了，是这份 PDF 本身就是图。
- CSV 是"全篇一张表"：工具只在表头列数发生变化时才认作新表头，两张结构相同但含义不同的表（比如"收入明细"和"支出明细"都是五列）会被并到一起，需要按页码或内容再拆。
- 表头只写一次：后面的行按字段名回填，原件里空着的单元格在 CSV 里也是空，不要当成 0。
- 合并单元格：跨行跨列的合并表头提取后常变成一堆空列，先看表头再决定要不要手工重建。
- Word 只求可读不求精确：页眉页脚、脚注、文本框、印章图片容易丢位或丢失，涉及签章页的，以原件为准。
- 输出文件被占用：同名文件正在 Word/WPS 里打开时保存会失败，且提示很轻，容易误以为转换成功。
- 长路径与中文路径：路径过深或含特殊符号时偶发写入失败，把文件先放到盘符根下的短目录再处理。

## 与包内其他工具怎么配合
- 04 图片文字识别工具：扫描件先 OCR 成文本或 Word，再回到本工具做结构化整理。
- 06A PDF数据提取工具：确认这份 PDF 主要是表格、且要按页按表分工作表时，换 06A 更直接。
- 06B PDF文件转换工具：只要整篇格式转换、不做表格提取时用它，产出更接近原件版式。
- 03 表格数据关联工具 / 02 数据分析关联查询工具：CSV 出来后做跨表关联、筛选异常，比在 Excel 里手工 VLOOKUP 可靠。
- 01 批量Word文档关键字检索：Word 版本可用于全批资料的敏感词、单位名称批量检索。
- 07 文本文档比对工具：两版合同或制度各转一份 Word，再比对增删改。
