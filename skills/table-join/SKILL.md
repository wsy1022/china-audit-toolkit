# 数据分析关联查询工具（表A × 表B 关联查询）

审计里最常见的动作：一张业务表（付款、发票、补贴发放）加一张台账表（合同、供应商、人员花名册），按一个共同字段对到一起，回答“这笔钱对应哪份合同”“这个人到底在不在编”。

## 什么时候用

- 两张表来自不同系统，只能靠一个共同字段对上：统一社会信用代码、身份证号、合同编号、凭证号、项目编码。
- 要查“表A里有多少条在表B里找不到”：左关联后看 B 侧字段是否为空，这是最省事的查漏口径。
- 逐笔比金额：关联后加一列差额，非零的就是疑点。
- 四种口径都要试：内关联看交集，外关联看并集（哪边多、多多少一目了然），右关联看“表B中未被表A覆盖的部分”。
- 不适合：三张以上表、或要留下“哪张表用哪个字段连”的说明——用包内 03 表格数据关联工具（关系表 + 连线 + SQL）。
- 不适合：只把多个文件或多张 Sheet 上下摞起来——那是 13 多表合一 / 14 多页合表；按单位拆成多文件是 12 单表拆分。

## 准备

- 工具位置：`组件/审计署工具/02数据分析关联查询工具/02安装包/Windows/数据分析关联查询工具.exe`（官方发布，不在本仓库内）。原包只提供国产系统版，本包内是按官方源码重打的 Windows 版，功能与源码一致。
- 文件格式：`.xlsx` 或 `.csv` 两种。老式 `.xls` 读不了，先另存为 `.xlsx`。
- 表头：必须在第一行，不能有空列名、不能有重名列；否则工具在选 sheet 时就会告警并清空字段列表，等于不让你往下做。
- 合并单元格：读入后只有左上角一格有值，其余为空。关联键落在合并区域内的，先在源表取消合并并向下填充。
- 编码类字段（身份证号、统一社会信用代码、以 0 开头的编号）在源文件里就设成文本格式，别等关联完再补前导零。
- 一个工作簿可以有很多 sheet，导入后逐张在下拉里选；CSV 没有 sheet 概念，下拉里显示的是文件名。
- 不需要 Office 或 WPS，全程离线，数据不出本机。

## 操作

1. 双击 exe 启动。左栏“表A选择”点“打开文件”，选文件后在“sheet名/csv文件名”下拉里选具体 sheet。
2. 字段表（两列：筛选、字段名）里勾选**只用于关联的键**，然后点“确认关联字段”。勾中的字段会全部变成关联键，不勾的列照样会带进结果。
3. 右栏“表B选择”同样操作：打开文件、选 sheet、勾字段，再点“确认关联字段”。顺序不能反，否则中间“关联设置”的第二列没有可选项。
4. 中间“数据分析”区核对“关联设置”：左列是表A的键，右列下拉是表B的键。工具按字段名相似度自动预选，**必须逐行核对**。
5. “关联方式”下拉里选左关联 / 右关联 / 内关联 / 外关联。
6. 点“开始分析”，进度按钮从“未开始”变“分析进行中”再变“分析完成”；随后点“保存”，选 `.xlsx` 或 `.csv` 落地。

## 输出与验收

- 输出物：一张明细表，列 = 表A全部列 + 表B全部列，两个关联键都保留（值相同，不必手工删）。结果里有关键编号列时优先存 `.csv`，避免转 xlsx 时丢精度。
- 行数守恒：先记下表A行数。左关联结果应等于或大于表A行数——大于说明表B的键一键多行，被放大了；内关联结果 = 两边真正匹配上的组合数；外关联结果 ≥ 两边较大者。
- 未匹配的去向：左关联里表B字段整行为空的那批，就是“表A有、表B没有”的记录，单独筛出来做成查漏清单；右关联反之。
- 金额守恒：对表A的金额列求和，左关联前后必须一致。结果表金额合计变大，是表B重复行把金额复制了，不是真的多出钱。
- 主键重复：关联前先对表B的键做一次计数，大于 1 的先查明原因（一户多址、一合同多补充协议都正常，但你要知道），再决定用哪种关联方式。

## 坑

- 把“金额”“日期”“摘要”一起勾进字段表：这些列也会被当成关联键，要求全等才匹配，结果行数骤减甚至为 0，看着像数据不匹配，其实是自己把键设多了。
- 类型不一致：表A的编号是文本“001”、表B存的是数字 1，工具会报关联字段类型不一致（提示里带 int64、object 字样），错误只闪在窗口底部状态栏，容易以为点了没反应。
- 相似度预选会骗人：表B里同时有“身份证号”和“身份证号码”时，下拉自动选中的那个可能不是你要的列，结果看着有值，其实对错了字段。
- 结果先写到系统临时目录的 temp_data.csv，保存成 xlsx 时再读回来：18 位身份证号、统一社会信用代码会变科学计数，末几位被抹掉。保存后第一件事就是检查这两类列。
- 两个窗口同时跑两份数据会抢同一个临时文件，后保存的那份可能是另一份的结果。一次只跑一份，保存完再开下一次。
- 选错 sheet 是最常见的“全空”原因：多 sheet 工作簿里字段名一样，下拉默认停第一张，关联完发现 B 侧全空，先回头看 sheet 名。

## 与包内其他工具怎么配合

- 两张表分散在多个文件里：先用 13 多表合一 / 14 多页合表摞成一张，再用本工具做横向关联。
- 需要交代关联逻辑、或涉及三张以上表：用 03 表格数据关联工具，把每张 sheet 变成关系表、连线建关联、生成 SQL 留档。
- 关联结果要按被审计单位分发：用 12 单表拆分，按单位字段拆成多份。
- 台账原始件是 PDF 或扫描件的：先用 05/06 PDF 提取、04 图片文字识别转成 Excel，再来关联。
