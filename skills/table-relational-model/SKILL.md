# 表格数据关联工具（Sheet 转关系表 + 连线建关联）

把一个 Excel 里的每张 Sheet 变成数据库里的一张表，用画布连线说明“哪张表的哪个字段连哪张表的哪个字段”，再由工具生成 SQL 查询——适合表多、关系复杂、以后还要按同样逻辑重跑的场合。

## 什么时候用

- 一个工作簿里有三张以上互相关联的表：凭证主表 + 凭证明细 + 科目表，或订单 + 订单明细 + 客户。
- 关联关系需要留痕：连线就是关系，生成的 SQL 能存进审计底稿，复核的人按 SQL 可以重跑一遍。
- 同一批数据要反复换条件查（换年度、换单位、加金额门槛），改 SQL 的 where 比每次重新点界面快。
- 需要多字段、多表串联（A 连 B、B 再连 C），02 只能两表对拼，做不了。
- 不适合：只有两张表、一次性拼一下——02 数据分析关联查询工具更快，不用建库。
- 不适合：只把多个文件或多张 Sheet 上下摞起来——用 13 多表合一 / 14 多页合表；按单位拆成多份是 12 单表拆分。

## 准备

- 工具位置：`组件/审计署工具/03表格数据关联工具/02安装包/Windows/表格数据关联工具.exe`（官方发布，不在本仓库内）。
- 文件格式：`.xlsx`。首行为表头，每张 Sheet 建成一张关系表，表名由“文件名 + Sheet 名”拼成。
- 表头不能重名、不能空列名；合并单元格先取消并向下填充，否则该列大量为空，连线后的匹配结果失真。
- 字段类型由工具自动判定，只有“数字”和“文本”两类：日期、带前导零的编号、金额里带千分位或单位的，都可能按文本入库。
- 明细表几十万行是逐行写入的，文件越大导入越慢；导入前删掉用不上的列和空行。
- 不需要 Office 或 WPS，全程离线；数据只落在本机的临时数据库里，不改源文件。

## 操作

1. 双击 exe 启动（官方说明写的是“选择在终端中打开”，Windows 下双击即可）。
2. 导入：选 Excel 文件，勾选要入库的 Sheet，转换成关系表。每张导入完成会提示“数据导入完毕！共 N 条”，把 N 记下来，后面核行数用。
3. 建关联：在画布上把一张表的字段拖线连到另一张表的对应字段，连线即“等值关联”。一对多、多对多都靠连线表达，连完在关系面板里核对左右字段有没有配错。
4. 生成并检查 SQL：工具按连线生成查询语句，可在编辑器里改输出列、加 where 条件、加排序；格式化功能只做排版，不改语义。
5. 执行查询，先看结果行数，再点预览（调用本机默认程序打开生成的 xlsx）。
6. 另存结果到目标目录，同时把 SQL 文本复制到审计底稿里存档。

## 输出与验收

- 输出物：查询结果 `.xlsx`（另存时自选路径）；建议另存一份 SQL 文本，作为可复现的证据。
- 行数守恒：导入时记的 N 必须等于源 Sheet 的数据行数（不含表头）。N 偏少说明有空行被跳过或表头判断错位。
- 结果核对：内连接的结果条数应等于手算的匹配组合数；左连接保留左表全部行，右表没匹配上的字段为空。
- 主键重复：连线前先对“一”端做主键唯一性检查（按关键字段分组计数）。键不唯一会让结果成倍膨胀，金额合计跟着翻倍。
- 未匹配的行：内连接里直接消失的那部分，要单独用左连接再查一次，确认是“确实没有”还是“格式不一致对不上”。

## 坑

- 表名是“文件名_Sheet名”，同一个文件换个版本再导入会先删后建同名表，之前的连线和 SQL 可能指向被替换的表；换版本时给文件名加日期。
- 类型只有数字和文本两类：18 位身份证号、统一社会信用代码按数字入库会丢精度，末几位变 0；金额列混着“1,200.00 元”这类写法会整列变文本，求和和比较都要先清洗。
- 文本比较是严格相等：“001”和“1”、“A公司”和“ A公司”（前面多一个空格）都不相等。关联前统一去空格、统一格式。
- 逐行插入，几十万行会明显卡；拆小文件或先删无关列，比等着它跑更快。
- SQL 编辑器是真执行：drop、delete、update 也会照跑。改的是本机临时库，源 Excel 不受影响，但表被删了得重新导入，别在唯一一份导入结果上盲试。
- 预览会在程序的工作目录里生成 xlsx，跑十次就堆十个文件，收工要清；正式交付走“另存”，别拿预览文件当成果。

## 与包内其他工具怎么配合

- 多文件同类数据先合并：一个文件多 Sheet 时本工具能直接建多表；分散在多个文件里的先用 13 多表合一。
- 拿不准两张表能不能对上：先用 02 快速试一次左关联，看空值比例；确认能对上再到 03 里固化成 SQL。
- 查询结果要按单位分发用 12 单表拆分；要和中文报表以外的外文报表对照用 15 财务报表中英翻译器。
- 源数据是 PDF 台账或扫描件的：先用 05/06、04 转成 Excel，再导入建表。
